# Noisy games on networks

A set of C codes that can be used to explore the role of noise on the collective dynamics of agents playing games on a specified network, in line with the specific approach described in the manuscript:

> Menon SN, Sasidevan V, & Sinha S (2018) Emergence of cooperation as a non-equilibrium transition in noisy spatial games. _Front. Phys._ <b>6</b>: 34.
> https://doi.org/10.3389/fphy.2018.00034
